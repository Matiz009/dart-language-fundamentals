# Dart Language Fundamentals

Dart practice files from a mobile app development course, covering the core language before moving on to Flutter.

## Topics

- Basics, booleans, type casting and user input: `basic.dart`, `bool.dart`, `typecasting.dart`, `input.dart`
- Collections: `list.dart`, `set.dart`, `maps.dart`
- Control flow: `loops.dart`
- OOP: `oop.dart`, `inheritance.dart`, `encapsulation.dart`, `student.dart`
- Employee class hierarchy: `employee.dart`, `dailyEmployee.dart`, `compensationEmployee.dart`
- Small text editor exercise: `textEditor.dart`

## Running

```bash
dart run loops.dart
```
